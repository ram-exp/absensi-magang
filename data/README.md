# Folder `data/`

Folder ini disediakan sebagai lokasi default untuk menyimpan file **backup/export** (`.json`) maupun **export laporan** (`.csv`) yang diunduh dari aplikasi melalui menu **Pengaturan → Backup & Restore Data** atau tombol **Export** pada halaman Absensi/Laporan.

Aplikasi ini tidak memiliki server/database sungguhan — seluruh data utama disimpan di **LocalStorage** milik browser pengguna. Folder ini hanya berfungsi sebagai tempat penyimpanan opsional untuk file backup yang ingin Anda commit ke repository (misalnya sebagai contoh data awal / seed data cadangan).

Tidak ada file yang wajib diletakkan di sini agar aplikasi berjalan.
